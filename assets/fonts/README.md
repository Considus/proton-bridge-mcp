# Brand fonts

Latin-subset WOFF2 files, embedded into the setup page as `data:` URIs so it
can render the brand faces without a single network request.

Both families are licensed under the SIL Open Font License 1.1. The full
licence text, with the upstream copyright statements it requires, is in
[OFL.txt](OFL.txt) alongside the font files. That file governs; what follows
is a summary.

- **DM Sans** — Copyright 2014 The DM Sans Project Authors.
  https://github.com/googlefonts/dm-fonts
- **Cormorant Garamond** — Copyright 2015 the Cormorant Project Authors.
  https://github.com/CatharsisFonts/Cormorant

The OFL permits bundling, embedding and redistribution, provided each copy
carries the licence and the copyright notice, which is why OFL.txt ships here.
The fonts are not sold separately; they ship solely as part of this software.
Anyone redistributing this project needs to keep OFL.txt with them.
